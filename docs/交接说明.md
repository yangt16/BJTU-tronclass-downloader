## 1. 项目是什么

把 TronClass 的课堂回放批量下载到本地，自动抽音轨（mp4 + m4a）。

- **只负责下载**：转写、总结、考点提取都不在这个项目里。
- 仓库：https://github.com/yangt16/BJTU-tronclass-downloader
- 用户：北交大威海校区（部分课程 Lancaster 联合培养）。
- 技术栈：Python 3.8+ 标准库 + ffmpeg（Windows 包内置 ffmpeg/ffprobe + Python 3.11 嵌入版）。

## 4. 代码结构

```
0-首次安装.cmd/.command    安装依赖（Windows 内置 ffmpeg 时只建目录）
1-开始下载.cmd/.command    唯一下载入口（弹菜单；拖清单到图标=跳过菜单）
2-清单规则.cmd/.command    按课程配置规则/产物
3-更新版本.cmd/.command    一键更新到最新 Release（保留数据）

tools/
  lectures.py      主编排：清单→解析→分组→筛选→预扫描→下载→校验→抽音轨→归档
  get_media.py     下载核心：请求头/分块/断点续传/分段并发/302 解析

  rules.py         按课程规则 lists\<课程>.rules（only/exclude/mode）
  ledger.py        下载台账 lists\downloaded.jsonl（删文件不重下）
  update.py        一键更新（查 releases/latest → 下载 zip → 覆盖程序文件）

  clean_archive.py 清理 har_archive/logs
  make_index.py    生成 lists\<课程>.md 索引
  check_urls.py    下载前预检
  lists.py         查看待下载清单
  fetch_ffmpeg.py  下载 ffmpeg（首次安装用）
  scrape_course.js 书签源码（抓清单）
  build_bookmarklet.js 编译书签/安装页
  build_release.py 打 zip 发布包
  test_*.py        20 套测试

docs/使用说明.md     完整手册
dist/               书签产物（bookmarklet.txt / bookmarks.html / install.html）
.github/workflows/ci.yml  CI：Windows / macOS / Linux(3.8 & 3.11) / package-mac
```

## 7. 发布流程（v4.x）

1. 在 `D:\course-notes-dev` 改代码 → 全量测试（20 套 + test_scrape）→ 提交
2. 改 `CHANGELOG.md`（未发布 → 版本号+日期），提交
3. 打 tag：`git tag -a v4.4 -m "..."`（tag 必须指向已提交的 HEAD）
4. 打 zip：`build_release.py`（win 会自动带 bin\ffmpeg；mac 不带）
5. 打安装包：
   - 依赖：Inno Setup 6（已装在 `%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe`，用户级）
   - `release\installer-src\app.iss` + `app.ico`（**gitignore，clone 不带**；新机器需从稳定版复制）
   - `tmp\python-embed.zip`（Python 3.11.9 嵌入版，10.7 MB，gitignore）
   - 步骤：解压 win zip 到 stage → 解压 python embed 到 stage\python → 拷 app.ico → 用 ISCC 编译
   - 注意：现有 `.iss` 里 `OutputDir`/`SetupIconFile` 写死了 `D:\course-notes\...`，换目录构建要改
6. 推送：`双击 tmp\push.cmd`（推 main + tag，带代理；tag 已存在时需 `--force`）
7. GitHub → Releases → Draft：
   - tag 选新版本
   - 说明粘贴 `release\vX.Y-notes.md`
   - 附件拖进 **Attach binaries**（zip ×2 + 安装包；不要把 exe 拖进描述框）
8. 发布后用固定链接验证 latest。

## 8. 已知坑（务必注意）

| 坑 | 说明 |
|---|---|
| `.cmd` 编码 | 必须**纯 ASCII + CRLF**，注释里不能有尖括号；`test_cmd_ascii` 会查 |
| `.command` 执行位 | 在 Windows 上 `git add` 新文件会丢 100755 → mac/Linux CI 红。必须 `git update-index --chmod=+x`；`test_shell` 已加 git 模式检查 |
| 嵌入式 Python | 安装包自带 Python 不会把脚本目录加进 `sys.path`；脚本 import 同目录模块前必须自己 `sys.path.insert`（menu.py 已修） |
| SmartScreen | 安装包未签名，首次运行点「更多信息→仍要运行」；只有 exe 会触发，zip 不会 |
| 大文件进 git | 朋友安装包 103.8 MB 曾被 `git add -A` 提交（>100MB 会导致推送失败）。`.gitignore` 已加 `/*.exe`；release/tmp/bin/media/lists 均已忽略 |
| GitHub 网络 | 本机直连 GitHub 被阻断（DNS 污染 + IP 阻断）；用代理 127.0.0.1:7897；push.cmd 已内置代理参数 |
| GitHub API 限流 | 匿名查 actions/releases 会 403；以页面为准 |
| DSH 沙箱 | 在 agent shell 里启动 GUI 安装器会失败/卡住（命名管道限制）；安装器只能人工双击验证 |
| v4.1/v4.2 Release | 只打了 tag，没发 Release（latest 曾长期停留在 v4.0） |
| 归档行为 | 带筛选/规则的清单跑完也会归档（完整清单在 har_archive） |
